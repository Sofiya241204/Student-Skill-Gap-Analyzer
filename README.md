# Student Skill Gap Analyzer 📊

A Python-based Data Analytics project that analyzes a student's current skills and compares them with the skills required for a target career. It identifies skill gaps and calculates skill coverage percentage.

---

## 🚀 Features

* Analyze required skills for different careers
* Compare student skills with industry requirements
* Identify missing skills
* Calculate skill coverage percentage
* Simple command-line interface
* Easy to extend for AI and web apps

---

## 🧠 How It Works

1. User selects a target career
2. User enters their current skills
3. System compares both lists
4. Outputs:

   * Required skills
   * Missing skills
   * Skill coverage percentage
